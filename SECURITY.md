# Sécurité

2Webp ne contient aucune fonction réseau, télémétrie ou collecte de données. Les conversions sont réalisées localement avec Pillow.

Pour vérifier une version distribuée, comparez son empreinte SHA-256 avec le fichier publié à côté de l’archive.

Les signalements de sécurité doivent indiquer la version, Windows utilisé et les étapes de reproduction.
