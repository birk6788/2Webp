# Système de design

## Identité

- fond sombre ;
- accent orange ;
- texte blanc / gris clair ;
- angles arrondis ;
- logo exact dans `assets/brand`.

## Mise en page

- colonne gauche fixe ;
- contenu principal compact ;
- fenêtre non maximisable ;
- aucune barre horizontale ;
- page Réglages avec en-tête et actions fixes, cartes défilantes ;
- page Convertir avec footer récapitulatif fixe.

## Hiérarchie de la page Convertir

1. accroche compacte ;
2. titre ;
3. sous-titre ;
4. cartes métiers ;
5. titre d'usage ;
6. presets ;
7. espace de séparation ;
8. zone de dépôt dominante ;
9. récapitulatif fixe.

## Presets

- hauteur : 124 px ;
- nom visible ;
- dimensions très lisibles ;
- mode à côté des dimensions ;
- qualité en dessous ;
- puce inactive blanche ;
- puce active orange ;
- contour actif orange.

## Zone de dépôt

- titre important ;
- description lisible ;
- barre de destination centrée, environ 48 % de la largeur ;
- bouton principal lisible ;
- confirmation temporaire de cinq secondes.

## Responsive Windows

Tester au minimum :

- 100 % ;
- 125 % ;
- 150 %.

Le design doit rester lisible sans maximisation.
