# Support

Pour signaler un problème, ouvrir une issue GitHub avec :

- version de 2Webp ;
- version de Windows ;
- mise à l'échelle Windows ;
- type de fichier utilisé ;
- étapes exactes ;
- message d'erreur complet ;
- capture d'écran si le problème concerne l'interface.

Ne jamais joindre une image confidentielle si elle n'est pas nécessaire à la reproduction.
