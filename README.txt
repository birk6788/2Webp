2Webp UI fix — build des 3 versions

Copie ces trois fichiers à la racine du projet 2Webp UI fix.

Le projet peut être sur F:, C:, D: ou ailleurs :
le script utilise automatiquement son propre dossier.

Double-clique sur :
LANCER_BUILD_3_VERSIONS.bat

Résultats créés dans release :
- 2Webp-v0.8.5-portable.exe
- 2Webp-v0.8.5-windows-x64.zip
- 2Webp-v0.8.5-setup.exe
- SHA256SUMS.txt

Pré requis :
- Python installé
- Inno Setup 6 installé
- projet complet contenant scripts\build-release.ps1
